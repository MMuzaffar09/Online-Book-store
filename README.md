# Online Book Store

A full-stack online bookstore application built with React, TypeScript, Vite, Tailwind CSS, and Supabase.

## Features
- Customer storefront
- Book browsing and search
- Authentication
- Admin portal
- Supabase database integration
- Phone authentication / OTP support
- Responsive UI

## Tech Stack
- React
- TypeScript
- Vite
- Tailwind CSS
- Supabase

## Local Setup

1. Install Node.js.
2. Clone this repository.
3. Install dependencies:

```bash
npm install
```

4. Create a `.env` file based on `.env.example` and add your Supabase configuration.
5. Start the development server:

```bash
npm run dev
```

## Build

```bash
npm run build
```

The `.env` file is intentionally excluded from Git. Never commit private credentials or secrets.
